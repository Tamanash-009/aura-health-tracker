# 🌿 AuraHealth: Smart Health & Fitness Dashboard

> **"Weightless" UI. Zero-Latency. Micro-Service Ready.**

Welcome to **AuraHealth**, a next-generation health tracking platform built with an "Anti-Gravity" architecture. We prioritize modularity, speed, and a seamless user experience. 🚀

## ✨ Features

- **📊 Real-Time Dashboard**: Visualize heart rate, steps, and sleep data instantly.
- **🔒 Secure & Stateless**: JWT-based authentication for ultimate security and scalability.
- **🎨 Weightless UI**: A stunning, responsive interface built with React & Tailwind CSS.
- **⚡ Reactive Data**: "Store-First" logic for optimistic UI updates.
- **🛠️ Micro-Service Ready**: Spring Boot backend structured for easy scaling.

## 🏗️ Tech Stack

### Frontend 🖥️
- **React 18** + **TypeScript**
- **Vite** (Blazing fast build tool)
- **Tailwind CSS** (Utility-first styling)
- **TanStack Query** (Async state management)

### Backend ⚙️
- **Spring Boot 3** (Java 17)
- **MySQL** (Relational Data)
- **Flyway** (Database Migrations)
- **Spring Security** (JWT Auth)

## 🚀 Getting Started

### Prerequisites
- **Java 17** or higher
- **Node.js 18+** & **npm**
- **MySQL** (Running on default port 3306)

### 1️⃣ Backend Setup
```bash
cd backend
# Update application.yml with your MySQL crdentials if needed
./mvnw spring-boot:run
```

### 2️⃣ Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
